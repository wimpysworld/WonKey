Macropad configuration tool for Linux

One key,
to rule them all.

Configure supported USB macropads and mini-keyboards from one Linux CLI. Bind keys, rotary knobs, macros, mouse actions, media controls, and RGB or LED lighting.

Get WonKey Quick start

Open source. Linux only. Supports XFKEY One Key Max (0112), CH57x Macropads (1189 / 514c : 8890, 8830, 8831, 8832, 8833, 8840, 8842, 8850, 8851), and SayoDevice Macropads (8089:0002..0005, 0009..000c, 000e).

Features

Make it yours

Control your macropad keys, knobs, and lighting from the command line. WonKey shows each change and verifies device state as it saves.

Explore the Wiki
01 Keys, knobs, and layers
Bind single keys or modifier chords (ctrl, shift, alt, super) with wonkey key. Target specific buttons or rotary knob directions (key1..key12, knob-left, knob-press, knob-right, knob1..knob4) and layers (--layer 1..15) on multi-control pads, or configure key press/release triggers with wonkey trigger on devices that support them.
02 RGB and LED lighting
Configure full 24-bit RGB colours and effects (static, breathe, flash, held, toggle, cycle-slow, cycle-fast, off) with wonkey rgb, or set CH57x LED backlight modes (off, reactive, cycle) with wonkey led.
03 Macros, media, mouse, and firmware
Bind multi-stroke key sequences (wonkey macro), consumer media controls (wonkey media), or relative mouse clicks, movement, and wheel actions (wonkey mouse) to any supported button or knob, and check or update official SayoDevice firmware with wonkey firmware.

How it works

Guarded writes from inspection to readback

Inspect connected macropads at any time. Write commands validate device capabilities, show the proposed change, and verify settings on supported hardware.

  1. wonkey

    Inspect connected pads

    Run wonkey with no arguments to list connected macropads, their USB paths, and their supported commands.

  2. wonkey key / media

    Bind keys and knobs

    Assign keys, macros, media actions, or mouse controls. Target specific keys, knobs, or layers when supported.

  3. wonkey rgb / led

    Configure lighting

    Set RGB lighting modes and hex colours with wonkey rgb or LED backlight modes (off, reactive, cycle) with wonkey led.

  4. Guarded writes

    Validate and save

    WonKey checks device capabilities and descriptors before every write, and verifies 128-byte readback where supported.

Unchanged settings on 0112 send no settings writes. Supports XFKEY One Key Max (0112), CH57x Macropads (1189 / 514c : 8890, 8830, 8831, 8832, 8833, 8840, 8842, 8850, 8851), and SayoDevice Macropads (8089:0002..0005, 0009..000c, 000e).

Install

Get WonKey on Linux

Install WonKey 0.1.1 with your Linux package manager. Choose a download for x86_64 or ARM64.

Compare downloads with the SHA-256 checksums before installation.

After installation, run wonkey --help. Help does not access the device.

WonKey needs permission to access the macropad's USB or hidraw device node. WonKey does not install udev permission rules. See the Wiki for hardware setup and all options.

Debian / Ubuntu

Download the .deb, then run its command from the download directory.

x86_64 package

sudo apt install ./wonkey_0.1.1_linux_amd64.deb

ARM64 package

sudo apt install ./wonkey_0.1.1_linux_arm64.deb
Fedora

Download the .rpm, then run its command from the download directory.

x86_64 package

sudo dnf install ./wonkey_0.1.1_linux_amd64.rpm

ARM64 package

sudo dnf install ./wonkey_0.1.1_linux_arm64.rpm
openSUSE

Download the .rpm, then run its command from the download directory.

x86_64 package

sudo zypper install ./wonkey_0.1.1_linux_amd64.rpm

ARM64 package

sudo zypper install ./wonkey_0.1.1_linux_arm64.rpm
Alpine

Download the .apk, then run its command from the download directory. The package is unsigned, so apk requires --allow-untrusted.

x86_64 package

sudo apk add --allow-untrusted ./wonkey_0.1.1_linux_amd64.apk

ARM64 package

sudo apk add --allow-untrusted ./wonkey_0.1.1_linux_arm64.apk
Arch Linux (AUR)

Install xfkey-wonkey-bin from the AUR. Requires yay.

yay -S xfkey-wonkey-bin
Binary archive

Download an archive, then extract and install it from the download directory.

x86_64 archive

tar -xzf WonKey_0.1.1_linux_amd64.tar.gz
sudo install -m 0755 wonkey /usr/local/bin/wonkey

ARM64 archive

tar -xzf WonKey_0.1.1_linux_arm64.tar.gz
sudo install -m 0755 wonkey /usr/local/bin/wonkey
Build from source

Requires Git, Go 1.25 or later, and just.

git clone --branch v0.1.1 --depth 1 https://github.com/wimpysworld/WonKey.git
cd WonKey
just build
sudo install -m 0755 ./wonkey /usr/local/bin/wonkey

The build replaces ./wonkey in the source directory.

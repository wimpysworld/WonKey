Macropad configuration tool for Linux

One key,
to rule them all.

Configure supported USB macropads and mini-keyboards from one Linux CLI. Bind keys, rotary knobs, macros, mouse actions, media controls, and RGB or LED lighting.

Get WonKey Quick start

Open source. Linux only. Supports XFKEY One Key Max, CH57x Macropads, and SayoDevice Macropads. See supported devices.

Features

Make it yours

Control your macropad keys, knobs, and lighting from the command line. WonKey shows each change and verifies device state as it saves.

Explore the Wiki
01 Keys, knobs, and layers
Bind single keys or modifier chords (Ctrl, Shift, Alt, Super) with wonkey key. Target buttons, knobs, and layers on multi-control pads. Set key triggers with wonkey trigger on supported devices.
02 RGB and LED lighting
Set 24-bit RGB colours and effects with wonkey rgb on XFKEY and SayoDevice pads. Set LED backlight modes (off, reactive, cycle) with wonkey led on CH57x pads.
03 Macros, media, mouse, and firmware
Bind key sequences (wonkey macro), media controls (wonkey media), or relative mouse actions (wonkey mouse) to any button or knob. Check or update official SayoDevice firmware with wonkey firmware.

How it works

Guarded writes from inspection to readback

Inspect connected macropads at any time. Write commands validate device capabilities, show the proposed change, and verify settings on supported hardware.

  1. wonkey

    Inspect connected pads

    Run wonkey with no arguments to list connected macropads, their USB paths, and their supported commands.

  2. wonkey key / media

    Bind keys and knobs

    Assign keys, macros, media actions, or mouse controls. Target specific keys, knobs, or layers when supported.

  3. wonkey rgb / led

    Configure lighting

    Set RGB lighting modes and hex colours with wonkey rgb or LED backlight modes with wonkey led.

  4. Guarded writes

    Validate and save

    WonKey checks device capabilities and descriptors before every write, and verifies 128-byte readback where supported.

Unchanged settings on XFKEY One Key Max send no settings writes. See the supported devices table for per-device capabilities and readback support.

Compatibility

Supported devices

WonKey discovers compatible USB macropads automatically and validates commands against each device's hardware capabilities.

CH57x Macropad (Gen 2) 1189 / 514c : 8830, 8831, 8832, 8833, 8840, 8842, 8850, 8851 Up to 12 keys, 4 knobs, 15 layers key, macro, mouse, media, led Layout and Layer 1 bindings
SayoDevice Macropad 8089:0002, 0003, 0004, 0005, 0009, 000a, 000b, 000c, 000e Up to 12 keys, 4 knobs, 5 layers key, macro, mouse, media, rgb, firmware Key bindings, lighting, and firmware version

Install

Get WonKey on Linux

Choose your distribution. Each repository is signed and keeps WonKey up to date.

  • Linux Debian and Ubuntu apt.wimpys.world
  • Linux Fedora and openSUSE rpm.wimpys.world
  • Linux Arch Linux pkg.wimpys.world
  • Linux Alpine Linux apk.wimpys.world
  • Nix Nix and NixOS nix.wimpys.world
  • Any Linux bin bin install github.com/wimpysworld/WonKey

WonKey needs permission to access the macropad's USB or vendor hidraw device node, and does not install udev permission rules. See the Wiki for hardware setup and all options.

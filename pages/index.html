WonKey

One key. Your rules.

A Linux command-line tool for the XFKEY One Key Max, model 0112. Change stored key assignments and RGB settings, not executable firmware.

Build from source Read the getting-started guide

Early-stage software

WonKey is still young and will change. F13 key output and steady-blue RGB persisted after reconnect on one user-tested unit. Other settings and devices remain unverified.

Features

What you can do

Set up the key and light from Linux.

01 Key remapping
Change the stored key assignment, for example to F13.
02 RGB settings
Choose RGB settings, including a steady colour.
03 Plans, backups and readback
Plan changes offline from a settings capture. Apply takes a fresh settings backup and checks readback after a write.

Get started

Build from source

Requires Linux and Go 1.23 or later. WonKey uses only the Go standard library.

Build WonKey

Get the source code, then run this command from the project root. It replaces any existing wonkey file.

go build -buildvcs=false -o wonkey ./cmd/wonkey

Start with the offline plan example. Read the hardware guide before device operations.
